# 💻 Programming in C – Lab

A collection of C programming laboratory experiments, practical programs, and problem-solving implementations developed as part of the B.Tech Computer Science and Engineering coursework.

## 📌 About the Repository

This repository contains C language programs designed to strengthen programming fundamentals and develop logical thinking through practical implementation.

It covers essential programming concepts, including decision-making, loops, functions, arrays, pointers, strings, structures, and file handling.

The main objective is to understand procedural programming and apply C programming concepts to solve computational problems.

## 🎯 Objectives

- Understand the fundamentals of C programming.
- Develop logical and analytical thinking.
- Implement decision-making and looping structures.
- Learn functions and recursion.
- Work with arrays, strings, and pointers.
- Understand structures and user-defined data types.
- Perform file handling operations.
- Implement searching and sorting algorithms.

## 🚀 Getting Started

### Prerequisites

Install the following:

- GCC Compiler
- Visual Studio Code or any C IDE
- Windows, Linux, or macOS

### 1. Clone the Repository

```bash
git clone https://github.com/arjunabalpande06/Programing-in-C-Lab.git
```

### 2. Navigate to the Project Directory

```bash
cd Programing-in-C-Lab
```

### 3. Compile a C Program

```bash
gcc filename.c -o output
```

### 4. Execute the Program

**Linux / macOS:**

```bash
./output
```

**Windows:**

```bash
output.exe
```

Replace `filename.c` with the name of the program you want to execute.
